# How Reliable Is a Predicted Side Effect? Conformal Coverage and Calibration of Molecular ADR Models under Scaffold Shift

Code and raw outputs for the paper *How Reliable Is a Predicted Side Effect?
Conformal Coverage and Calibration of Molecular ADR Models under Scaffold
Shift*. The study applies split-conformal prediction to multi-label SIDER
side-effect models (1427 drugs, 27 MedDRA system-organ classes) on two
scaffold-shifted test sets (scaffold-204 and OGB/Hu) and examines coverage,
informativeness against a majority baseline, per-molecule coverage,
calibration and applicability domain. Start with
[Conformal study: reproduction](#conformal-study-reproduction) below.

The models come from an earlier ablation of a GIN-based graph neural network
against classical fingerprint models (Random Forest, XGBoost,
HistGradientBoosting) trained on the same splits, and blends of the two. That
ablation is described next, in the repository's original summary.
## Headline result

Macro-AUC (mean over the 27 tasks) on three separate splits:

| Model | Scaffold-204 | OGB/Hu scaffold | Random 80/10/10 (mean ± std of 3) |
|---|---|---|---|
| Baseline GIN (ablation reference) | 0.568 | 0.558 | — |
| GIN A3 (RDKit descriptors) | 0.620 | 0.632 | — |
| GIN A3+A5 (descriptors + SWA) | 0.622 | 0.629 | 0.670 ± 0.012 |
| **RF, ECFP4 + RDKit descriptors** | **0.616** | **0.678** | **0.680 ± 0.018** |
| GIN A3+A5 + RF blend | 0.631 | 0.672 | 0.686 ± 0.013 |

GIN rows are 5-seed ensembles. The paper's OGB/Hu blend uses A3 instead of
A3+A5 (0.673); see `docs/reproduction.md`.

An untuned Random Forest matches or beats the graph neural network on this
dataset; the blend clearly beats the GNN but does not significantly beat the
RF. Confidence intervals, paired tests and the per-split numbers are in the paper.

The table above reports the values used in the paper. A later verification
rerun re-evaluated the stored GIN checkpoints, retrained the RF, and rebuilt
the blends without overwriting the paper outputs. The refreshed values were
0.615 / 0.678 / 0.680 for RF and 0.631 / 0.672 / 0.686 for the A3+A5+RF
blend (scaffold / OGB / random mean). The small RF differences are expected
when a parallel forest is retrained; the reported conclusions do not change.
The verification report is described in
[`docs/reproduction.md`](docs/reproduction.md).

## Setup and usage

Install the dependencies and run commands from the repository root:

```bash
pip install -r requirements.txt   # PyTorch, PyTorch Geometric, RDKit, DeepChem, scikit-learn, XGBoost
PYTHONPATH=. python -m scripts.train.scaffold204_baseline
```

Raw datasets are not kept in the repository; download instructions are in
the Datasets section below.

## Conformal study: reproduction

Every number of the conformal paper comes from the scripts below; raw outputs
are tracked in [`outputs/conformal/`](outputs/conformal/) (about 2 MB:
per-molecule probabilities as `.npz`, `results_*.json`, `*.csv`). They contain
no drug names; molecules are identified by their SIDER SMILES strings. Data source:
SIDER from MoleculeNet via DeepChem (`data/raw/sider.csv.gz`, downloaded on
first use) and the OGB `ogbg-molsider` scaffold split; the fixed split lists
are in `data/raw/`. Environment: Python 3.10 with the pinned `requirements.txt`
(RDKit, scikit-learn 1.7.2, SciPy, NumPy; PyTorch + PyG only for `--part gin`).
Run from the repository root with `PYTHONPATH=.`; all conformal quantities
use `RandomState(0)` bootstraps (2000 resamples).

| Step | Command (`python -m ...`) | Writes to `outputs/conformal/` | Used for |
|---|---|---|---|
| 1 | `scripts.analysis.conformal_probs --part rf` | `rf_{scaffold,ogb_scaffold}.npz` | out-of-fold (scaffold-grouped, 5 folds), stopping-slice and test RF probabilities |
| 1 | `scripts.analysis.conformal_probs --part gin` | `gin_*.npz` | GIN A3+A5 5-seed ensemble probabilities (needs the stored checkpoints; GPU) |
| 1 | `scripts.analysis.conformal_probs --part yrand` | `yrand_*.npz` | Y-randomisation negative control (10 permutations) |
| 2 | `scripts.analysis.conformal_label_counts` | `label_counts.csv` | calibration/test class counts per endpoint |
| 3 | `scripts.analysis.conformal_analysis` | `results_{split}.json`, `results_flat.csv` | split-conformal coverage (standard and Mondrian), calibration (ECE, Platt), applicability domain, negative control |
| 4 | `scripts.analysis.conformal_extras` | `results_boot_*.json`, `results_gated_*.json`, `results_selective_*.json`, `results_molecule_level_*.json`, `results_extras_summary.csv` | prevalence-gated Mondrian (tau 0.10 / 0.20), molecule bootstrap, singleton accuracy/PPV/NPV, per-molecule simultaneous coverage |
| 5 | `scripts.analysis.conformal_repeated_cv` | `repeated_cv_*.json`, `repeated_cv_summary.csv` | calibration-set variance over 10 repeated scaffold-grouped CV assignments |
| 6 | `scripts.analysis.conformal_cluster` | `results_cluster_*.json`, `results_majority_baseline_*.json`, `results_cluster_summary.csv` | scaffold-cluster bootstrap, scaffold-balanced coverage, exact majority baseline |

Run order: 1 -> 2 -> 3 -> 4 -> 5 -> 6 (steps 4-6 read the outputs of the
earlier ones). `conformal_probs --part rf` and `--part yrand` need only the
fixed splits and SIDER; `--part gin` additionally needs
`outputs/eval/ginv2_heldout_ensemble_*` and the GIN checkpoints from the
ablation (see [docs/reproduction.md](docs/reproduction.md) §2, §4), which are
not tracked; its probabilities are provided as `gin_*.npz`. Steps 2-6 can be
run from the tracked `.npz` files alone.

```bash
PYTHONPATH=. python -m scripts.analysis.conformal_probs --part rf      # also: --part gin, --part yrand
PYTHONPATH=. python -m scripts.analysis.conformal_label_counts
PYTHONPATH=. python -m scripts.analysis.conformal_analysis
PYTHONPATH=. python -m scripts.analysis.conformal_extras
PYTHONPATH=. python -m scripts.analysis.conformal_repeated_cv --repeats 10
PYTHONPATH=. python -m scripts.analysis.conformal_cluster
```

**Verification status.** Steps 3-6 were rerun from the tracked `.npz` files in
the pinned environment of `requirements.txt` (Python 3.10.14, scikit-learn
1.7.2). All 22 JSON/CSV files in `outputs/conformal/` that these steps write
(including the 10 repeated scaffold-grouped CV results and the Random Forest
retrained within them) were reproduced identically to 1e-9 (CSV files
byte for byte). Not rerun: `conformal_probs --part gin` (needs the GIN
checkpoints, which are not tracked) and the full `--part rf` / `--part yrand`
refits (a single RF fold was refit and matches the stored out-of-fold
probabilities exactly).

The Random Forest retraining is scikit-learn-version sensitive: with
scikit-learn 1.9.1, `RandomForestClassifier(class_weight="balanced")` on the
27-column multi-output target returns degenerate probabilities (mean 0.11
against 0.58), so keep the pinned version.

Paper elements and their sources: the coverage/efficiency table
(`tab:coverage`) reads `results_{split}.json`; the gated table
(`tab:gated`) `results_gated_*.json`, `results_cluster_*.json` and
`results_majority_baseline_*.json`; the per-molecule table (`tab:molecule`)
`results_molecule_level_*.json`; the prevalence/singleton and
coverage-versus-similarity figures are drawn from `results_extras_summary.csv`,
`results_selective_*.json` and the applicability-domain block of
`results_{split}.json` (mapping inferred from the script outputs); the calibration-set variance
`repeated_cv_*.json`. The LaTeX tables and figures are typeset from these
files by tooling that lives with the manuscript, not in this repository.
`endpoint_prevalence.csv` (calibration vs test prevalence per endpoint) is
derived from the `rf_*.npz` labels and has no generating script here.

## Evaluation principles

- **The only reportable number comes from the held-out test set.** The
  stopping-slice score, used for early stopping and epoch selection, is never
  reported as performance.
- **Splits are never mixed.** Scaffold-204 (ours), OGB/Hu scaffold (matching
  the literature) and random 80/10/10 are separate families; numbers are
  compared only within a family.
- **Split lists are fixed on disk.** If the dataset changes the code raises an
  error instead of silently producing a new split.
- **Comparisons are paired.** Paired bootstrap over the same molecules with
  2000 resamples; confidence intervals are bootstrapped too. No
  multiple-comparison correction is applied.
- **Verification is non-destructive.** Reproducibility reruns write to a
  separate output directory and do not replace the paper's original results.

## Datasets and data preparation

From [MoleculeNet](https://moleculenet.org/) via DeepChem: SIDER (target),
Tox21, ClinTox, BBBP, HIV, MUV (auxiliary tasks). DeepChem downloads and
caches them under `data/raw/` on first use (`src/data/datasets.py`), so no
manual download is needed for these. The split used for a like-for-like
comparison with the literature is the [OGB](https://ogb.stanford.edu/)
`ogbg-molsider` scaffold split; its files are expected under
`data/raw/ogb_sider_scaffold/` (`src/splits.py`); these four small files (`mol.csv.gz` plus the `train`/`valid`/`test` index lists, which define the OGB/Hu test identifiers) are tracked in the repository.

Already in the repository and required: the OGB/Hu split files under `data/raw/ogb_sider_scaffold/`, the fixed split lists
`data/raw/gin_v2_*_ids.json` and the RDKit descriptor normalizers
`data/raw/ginv2_rdkit_descriptor_normalizer*.json`. Without them the splits and
normalizations would be regenerated and the reported numbers would change.

ChEMBL target features (101 dimensions, version 2) are rebuilt with:

```bash
PYTHONPATH=. python -m scripts.data.fetch_chembl_targets
PYTHONPATH=. python -m scripts.data.fetch_chembl_potency
PYTHONPATH=. python -m scripts.data.build_target_features   # writes data/raw/chembl_target_features.json
```

`configs/default.yaml` reads the version-2 file as
`data/raw/chembl_target_features_v2_backup.json`; copy the freshly built file to
that name. The ChEMBL API is queried live, so rebuilt features may differ
slightly from the ones used in the paper.

## Reproducibility check

`scripts/analysis/reproducibility_test.py` re-evaluates stored checkpoints,
retrains the classical models and rebuilds the blends into `outputs/eval_repro/`
(never overwriting `outputs/eval/`):

```bash
PYTHONPATH=. python -m scripts.analysis.reproducibility_test --tier 1
```

Tier 1 covers the models of the per-endpoint table. In the last run all six
GIN ensembles and the OGB/Hu RF reproduce exactly; the RF models on the
scaffold-204 and random splits differ by at most 7e-4 in macro-AUC
(probabilities by at most 6e-3, about three trees out of 500), which is why they
are flagged against the strict 1e-6 tolerance.
