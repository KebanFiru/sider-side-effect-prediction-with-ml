# SIDER Side-Effect Prediction: Graph Neural Networks and Classical Models

Predicting the side-effect profile of approved drugs from molecular structure.
The target task is **SIDER**: 1427 drugs, 27 side-effect categories (MedDRA
system-organ classes), multi-label classification.

This repository holds the experimental code accompanying a paper: an ablation
of a GIN-based graph neural network, classical fingerprint models (Random
Forest, XGBoost, HistGradientBoosting) trained on the same splits, and blends
of the two.

## Headline result

Macro-AUC (mean over the 27 tasks) on three separate splits:

| Model | Scaffold-204 | OGB/Hu scaffold | Random 80/10/10 |
|---|---|---|---|
| Baseline GIN (ablation reference) | 0.568 | 0.558 | — |
| Best GIN component (2.3, RDKit descriptors) | 0.620 | 0.632 | 0.665 |
| **RF, ECFP4 + RDKit descriptors** | **0.616** | **0.678** | **0.680 ± 0.018** |
| GIN + RF blend | 0.631 | 0.673 | 0.687 |

An untuned Random Forest matches or beats the graph neural network on this
dataset; the blend clearly beats the GNN but does not significantly beat the
RF. Confidence intervals, paired tests and the per-split numbers are in the paper.

## Setup and usage

Install the dependencies and run commands from the repository root:

```bash
pip install -r requirements.txt   # PyTorch, PyTorch Geometric, RDKit, DeepChem, scikit-learn, XGBoost
PYTHONPATH=. python -m scripts.train.scaffold204_baseline
```

Raw datasets are not kept in the repository; download instructions are in
the Datasets section below.

## Repository layout

| Path | Contents |
|---|---|
| `configs/default.yaml` | The single config file: data, model, training, ablation flags |
| `src/data/` | Featurization (`featurize.py`), graph dataset and cache (`datasets.py`) |
| `src/models/gin.py` | GIN encoder |
| `src/train.py` | Training loop, early stopping, SWA, resume after interruption |
| `src/train_ensemble_*.py` | Multi-task / multi-seed training drivers |
| `src/splits.py` | The three split families; split lists are read from disk, never regenerated |
| `src/losses.py` | Asymmetric loss, task weighting |
| `src/eval_metrics.py` | Macro-AUC/AUPR, bootstrap confidence intervals, paired bootstrap p-values |
| `scripts/data/` | Dataset download, ChEMBL target features, label audit |
| `scripts/train/` | Training entry points, named `<split>_<model>`: `scaffold204_*` (baseline, a1_capacity, a2_asl, a3_descriptors, a4_uncertainty, a5_swa, a3a5), `ogb_*` and `random_*` (baseline, a3, a3a5) |
| `scripts/eval/` | `single_checkpoint`, `ensemble`, `classic` (RF/XGBoost), `blend` |
| `scripts/analysis/` | Paper analyses (SRD, Friedman/Wilcoxon, applicability domain, Y-randomisation), auxiliary-data stacking, split-paradigm comparison |
| `scripts/run/` | Shell drivers that chain training and evaluation |
| `docs/reproduction.md` | Which command produces which reported number |
| `outputs/` | Experiment outputs — **not** tracked; regenerated by the commands |

Model names follow the paper: baseline, A1 capacity, A2 ASL, A3 RDKit
descriptors, A4 uncertainty weighting, A5 SWA, A3+A5 combined.

## Documentation

[docs/reproduction.md](docs/reproduction.md) lists, for every reported number,
the command that produces it and the file it lands in.

## Evaluation principles

- **The only reportable number comes from the held-out test set.** The
  stopping-slice score, used for early stopping and epoch selection, is never
  reported as performance.
- **Splits are never mixed.** Scaffold-204 (ours), OGB/Hu scaffold (matching
  the literature) and random 80/10/10 are separate families; numbers are
  compared only within a family.
- **Split lists are fixed on disk.** If the dataset changes the code raises an
  error instead of silently producing a new split.
- **Comparisons are paired.** Paired bootstrap over the same molecules with
  2000 resamples; confidence intervals are bootstrapped too. No
  multiple-comparison correction is applied.

## Datasets

From [MoleculeNet](https://moleculenet.org/) via DeepChem: SIDER (target),
Tox21, ClinTox, BBBP, HIV, MUV (auxiliary tasks). The split used for a
like-for-like comparison with the literature is the [OGB](https://ogb.stanford.edu/)
`ogbg-molsider` scaffold split. Target/potency enrichment is derived from
ChEMBL's public bioactivity data.
